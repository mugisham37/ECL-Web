§3 · Inspiration Brief (locked)

Visual DNA, lifted from the references

Derived from the supplied images and locked for every subsequent flow. The convergence — violet accent, deep-indigo canvas, a blueprint/matrix grid, serif-display-meets-mono — maps directly onto the product's core artifact: the PD transition matrix.

Palette

Violet #6D4AFF primary, cyan data secondary, off-white light / deep-indigo dark. Green is success-only — never brand.

Type

Spectral display · Hanken Grotesk UI · Geist Mono figures.

System

Density 4 · motion calm · border-first · illustration none. Grid motif loud on marketing, a whisper in-app.

Pairing logic

Spectral (transitional serif, high weight-contrast) carries voice on marketing & hero KPIs. Hanken Grotesk (humanist neo-grotesque, tall x-height) holds dense UI at 14px. Geist Mono shares Hanken's proportion and supplies tnum figures + schematic labels.
